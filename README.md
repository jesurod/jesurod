# 🧩 Sobre mí

Actualmente curso Ingeniería Informática y me encuentro desarrollando proyectos técnicos enfocados en automatización, monitorización de sistemas, diseño de agentes inteligentes y gestión de infraestructuras. Me interesa entender cómo funcionan las cosas por dentro y construir soluciones que realmente aporten eficiencia y control sobre los sistemas.

## 📚 En qué estoy trabajando ahora
Estoy profundizando en temas como:
- Configuración y automatización de servidores Linux usando **Ansible**
- Monitorización con **Prometheus** y **Grafana**
- Pruebas de carga y rendimiento con **JMeter**
- Implementación de algoritmos de búsqueda (**Dijkstra**, **A\***), comportamiento reactivo y deliberativo para agentes
- Consultas complejas y modelado de bases de datos con **SQL** y **Álgebra Relacional**

## 🛠️ Tecnologías con las que he trabajado
- **Lenguajes**: Python, C++, Bash, SQL
- **Sistemas y DevOps**: Ansible, Docker, Prometheus, Grafana, Node Exporter, systemd
- **Entornos Linux**: Rocky Linux, Ubuntu
- **Servidores web**: Nginx, Apache
- **Pruebas y automatización**: JMeter, scripts de shell
- **IA aplicada**: diseño de heurísticas, motores de búsqueda para juegos y agentes autónomos
- **Web**: HTML, configuración de servicios web

## 🔎 Temas que me interesan
