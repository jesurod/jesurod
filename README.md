Desarrollo de modelos predictivos de Machine Learning (incluyendo sistemas de predicción de *churn*), integración de bases de datos y visualización interactiva mediante un dashboard en Streamlit. *(Python, PostgreSQL, Streamlit)*
- 📈 **Optimización de Carteras con Metaheurísticas**: Diseño, *benchmarking* y documentación de algoritmos de búsqueda basados en poblaciones aplicados a datasets financieros.
